# DUST DIVISION

一款可在浏览器内完成单次远征的单人实时 3D 游戏。六轮勘探车、工业区、编队和守卫共享同一张地图与存档。可以按 1–4 自由查看四个模式，也可以从主入口驾驶起步。

## 快速开始

需要 Node.js 22.18 或更新版本（推荐 24 LTS）。

```sh
npm ci
npm test
npm run build
npm run dev
```

开发服务器显示本地访问地址。生产版本使用 `npm run preview`。静态站点根目录为 `dist/`，资源使用相对路径。运行时无需远程素材、账号或服务器。

## 一轮远征

1. **荒原**。点击 **Enter Sector**。用 W/S 加速、制动或倒车，A/D 转向，按住 Shift 或空格漂移。接近物资箱后按 E 回收合金。车队补给会开启 45 秒派送，在 Motor Pool 附近交货可获得 10 合金。
2. **街区**。按 2 查看建筑标牌。Switchyard 进入供电系统，The Foundry 进入精炼工具。Motor Pool 消耗合金提升基地等级、车速、小队耐久及伤害。Nightwatch 进入战前编队。
3. **基建**。在 7×7 工业区中选择模块并点地块铺设。发电机初始供电 8，中继连接相邻八格。采集器用电 2，精炼厂用电 3。传送带允许直连和 45° 转角。每条生产链需要供电的采集器、传送带与供电的精炼厂。观察拆除中继后的产量变化。拆除返还一半造价，向下取整。
4. **夜袭**。按 4 打开编队，选择领队，再在 3×3 部署棋盘上移动或交换队员。直线阵增加 8% 伤害，楔阵增加 12% 破韧，疏阵减免 15% 受击伤害。首位 Vale 延长弹反窗口，Iris 延长共鸣并增加反应伤害，Flint 加快破韧。出击后，不同角色短时间内连续命中会触发共鸣。观察守卫的扫击、突进与砸地前摇。三阶段会改变招式序列、节奏与伤害。核心暴露后可贴近按 F 处决。
5. **撤离**。可随时呼叫撤离。穿越搜刮区，进入信标范围并守住五秒。离开范围会中断读秒。成功撤离将携带资源入库并推进至次日；团灭或超时失去本次携带物资。回收的核心可为每台发电机增加最多 3 单位电力。夜袭基础时限 110 秒，电网余量最多追加 18 秒。

## 操作

| 按键 | 功能 |
| --- | --- |
| 1 / 2 / 3 / 4 | 荒原、街区、基建或撤离、编队或 Boss |
| Enter / R | 主入口出发 / 驻车 |
| WASD 或方向键 | 驾驶或战场移动 |
| Shift / Space | 载具手刹 |
| E | 搜集、据点交互、撤离区交互 |
| J / 点击战场 | 近战或角色攻击 |
| K / Space | 弹反 / 战场闪避 |
| Q / F / X | 切人 / 处决 / 呼叫撤离 |
| H / Esc / M | 游戏指南 / 设置 / 静音 |

战斗、建设、编队与撤离操作均有可点击控件。触控设备会显示方向键。夜袭时切到 1、2 可安全查看其他模式，切回战场继续。设置和指南打开期间暂停模拟。存档写入当前浏览器的 localStorage，包括建筑、编队和进行中的夜袭。

## 渲染与声音

- TypeScript、Three.js/WebGL2，90 Hz 固定步长车辆动力学与战斗模拟。车辆以纵向速度和横向滑移积分，地形梯度影响牵引，建筑基础参与碰撞。
- 主入口将沙漠环境绘景与现场渲染的六轮车组合。镜头穿入场景时，绘景投影到实际几何体，随后由实时城市、管网和战场接替。使用临界阻尼相机、焦距插值、景深、风沙、环形高光及冲击后处理。
- 模具磨损、岩层、金属、玻璃反射和尘粒使用自定义 GLSL。场景实例化复用大量机械零件。WebGL2 不可用时采用可操作的 Canvas2D 兼容视图。
- Web Audio 实时合成引擎、滑移、风声、战斗提示和 UI 声音。首次点击或按键后启动。设置中可以调节音量、渲染精度及冲击动效。右下角 FPS 为当前设备实测值。

## 验证与发布

`npm test` 验证驾驶、碰撞、地形、运输、管网、弹反、共鸣、三阶段处决、撤离与存档恢复。页面包含完整的键盘和鼠标入口，可独立复验。

推送到目标 GitHub 仓库的 `main` 分支后，`.github/workflows/pages.yml` 会运行测试、构建并部署。仓库 Pages 的构建来源需为 **GitHub Actions**。也可直接将整个 `dist/` 交给静态服务器。

`npm run offline -- ./Dust-Division.html` 生成内嵌脚本、字体与美术资源的单 HTML 离线版，可双击运行。
